# 中立性チェック（公開前の目視レビュー）

このサイト「自治体Watch」を一般公開する前に、**画面が中立に見えるか**を人の目で一度確認する作業のチェックリストです。この作業は自動テストではできないため、人が実際の画面を見て判断します。

このチェックリストは、**この作業を初めてやる人（プロジェクトの内部事情を知らないボランティアや引き継ぎ担当者）**が、これ一枚を読めば作業できることを目指して書いています。

---

## 0. まず「中立」とは何か（このサイトの一番大事なルール）

このサイトの根本方針は、**「どの自治体が良い・悪い」をサイトの側が決して言わない**ことです。数字や制度を事実としてそのまま並べ、良し悪しの判断は見た人自身に任せます。これが崩れると、サイトが特定の立場を持っていると受け取られ、市民の判断を誤らせてしまうため、最も守るべき一線とされています。

この方針から、画面上で**やってはいけないこと**が4つあります。作業ではこの4つを探します。

| 用語 | 意味 | なぜダメか |
|---|---|---|
| **信号色** | 赤・黄・緑を「赤＝危ない／緑＝安全」という意味で使うこと | 数字は「基準からどれだけ離れているか」を示すだけで、危ない/安全の判定ではない。色で判定に見せると誤り |
| **順位（ランキング）** | 値の大小で自治体を並べ替えて「1位・最下位」に見せること。「ランキング」「ベスト」「ワースト」などの言葉 | 自治体に順位や点数をつけること自体が「評価しない」方針と正面から衝突する |
| **評価語** | 「危険」「悪化」「深刻」「優良」など、良い/悪いを含む言葉 | サイトが価値判断を下したことになる。使ってよいのは「多い/少ない/大きい/程度」など量だけを表す言葉 |
| **政治的な示唆** | 特定の政党・政策・立場に有利/不利な印象を与える表現や強調 | 中立の立場が崩れる |

### 大事な注意：「厳しすぎ」て正常な表示まで違反にしないこと

禁じられているのは、**サイトが評価・順位づけ・信号色を「行うこと」**です。次のようなものは**違反ではありません**。取り違えないでください。

- 数字が自然に大小を持っていること（人口が多い/少ない、金額が大きい/小さい）は当たり前で問題なし。
- 法律で決まっている区分を**事実として**表示すること（例:「早期健全化基準に該当」）は、法律の言葉をそのまま載せているだけなので問題なし。
- データが無い箇所に「データ未整備」「確認できず」と表示すること自体は問題なし。

各チェック項目には「**これはOK（違反でない）**」の例も書いています。迷ったらそれと見比べてください。

## 1. この作業のやり方（手順）

### 誰が・何を用意するか
- 実施する人:〔　　　　〕（この作業を担当する人の名前を記入）
- 用意するもの: 公開前のサイトを表示できる状態（開発中の画面でよい）。
- **パソコンの画面幅と、スマホの画面幅の両方**で見ること。スマホでは並びや色が変わることがあり、別々に確認が必要です。

### 進め方
1. このチェックリストの **§3（画面ごとのチェック項目）** を、上から順に1画面ずつ見ていきます。
2. 各項目には「**画面のどこを見るか**」「**こう見えたらOK**」「**こう見えたらNG**」が書いてあります。実際の画面と見比べて、3つのどれかで判定します。

   - **OK** … 問題なし。
   - **要確認** … 違反かどうか自分で判断がつかない。→ §4の記録表に書き、あとで判断できる人（運営者）に相談する。**その場で「OK」に流さない。**
   - **NG** … 上の4つ（信号色・順位・評価語・政治的示唆）のどれかに当てはまる。→ §4の記録表に書く。

3. 判定が **NG または 要確認** になった項目は、必ず **§4の記録表**に1行書きます（画面名・何が問題か・スクリーンショットがあれば添付）。
4. 全画面を見終わったら、§4に集まった「NG」を直す作業（＝実際に色や言葉やタイトルを修正するプログラム側の作業）に回します。**このチェックリストの担当者は「見つけて記録する」ところまで**が仕事です。直すのは実装担当です。
5. §4の完了条件をすべて満たしたら、この中立性チェックは完了です。**一度やれば、画面に変更が入るまで再度やる必要はありません**（再度必要になる条件は §5）。

## 2. 各画面で共通して探すもの（早見表）

§3で画面ごとに細かく見ますが、どの画面でも共通して探すのは次の4つです。§3が長く感じたら、まずこの4つを頭に入れてください。

1. **色**: 赤・黄・緑の「危ない/安全」の色分けが出ていないか。全体が青緑（ティール）系に収まっているか。
2. **並び順**: 良い順・悪い順に並べ替えて順位に見える表示がないか。
3. **言葉**: ラベルや説明に「危険・悪化・優良」などの良し悪しの言葉がないか。
4. **タイトル**: 見出しや機能名に「ランキング」「ベスト」などの順位・評価の言葉がないか。

## 5. もう一度このチェックが必要になるとき（再チェックの条件）

このチェックは公開前に一度やれば済みますが、あとから画面に次のような変更が入った場合は、**変更した部分についてもう一度**このチェックをしてください。

- 表示する項目を増やした
- 並び順や、最初に表示される内容を変えた
- 新しい集計値（他との比較など）を追加した
- スマホでの見え方を変えた
- SNS用の画像や、検索結果に出る文言を変えた
- 議会データで新しい種類の議会に対応した

これらは「画面の枠組み」が変わる変更で、枠組みが変わると中立の見え方も変わりうるためです。逆に、データの数値を最新に更新しただけ、といった変更では再チェックは不要です。
