## 1. 区分定義（content-spec §0基本事項に準拠）

- 全国比較は「当該自治体と**同一の類似団体区分**にある市町村の平均値」との比較を既定とする（`content-spec-v1.md`／新IA §0.2）。
- 区分の束ね方（新IA §0基本事項）：**「指定都市・中核市・施行時特例市・特別区」は一括り**。その他の**一般市16類型・町村15類型はそのまま**用いる。
- この束ね規則は区分マスタの原区分コードに対する**決定的な写像**（マッピングテーブル）として実装する。写像は1箇所で定義し、全指標が共有する（区分の定義が指標ごとにぶれない）。

## 2. パイプラインの段（既存収集段の後に追加する最終段）

```
[収集段] 各指標の全国集約ファイルを取得（M1/M2/M3＝既存、1-1a〜3-3＝Batch1で経路確定）
   ↓
[正規化段] 各指標を「団体コード(6桁)｜指標値」の長い表に正規化
   ↓
[結合段] 区分マスタ（団体コード→原区分→束ね後区分）を team に結合
   ↓
[集計段] ★本設計の主対象
   - 全国平均：全母集団の平均（指標ごとに定義された母集団で）
   - 類団平均：束ね後区分ごとの groupby 平均
   - 順位・百分位：data-schema §3.2 の rank/rank_out_of/percentile
   ↓
[書き戻し段] 各自治体JSONのレコードに比較値を書き戻す（下記スキーマ）
```

## 3. 集計の定義（式）

母集団を M（ある指標の全国データを持つ全市区町村）とし、自治体 i の区分を g(i)（束ね後）とする。

- **全国平均**：avg_national = mean( value(j) for j in M )
- **類団平均**：avg_group(i) = mean( value(j) for j in M if g(j)==g(i) )
- **順位**（§3.2）：rank(i) = i の value の降順/昇順順位（指標ごとに向きを定義。金額・率など「高い＝上位」か否かは指標定義に従う）。rank_out_of = |M|。percentile(i) = i の百分位。
- **区分内順位**（任意・V2）：rank_in_group(i)、rank_in_group_out_of = |{j in M: g(j)==g(i)}|。

**加重の扱い（重要・中立性）**：平均は原則**単純算術平均**（自治体を1単位とする）とする。人口加重等の加重平均は「どの重みを選ぶか」に価値判断が入りうるため既定にしない。ただし元統計が加重平均を公式値として持つ場合（例：M2介護保険料の全国加重平均）は、**公式値はそのラベルで別途保持**し、自作の単純平均と混同させない（M2 JSONが既に `premium_average_source: official/unweighted_mean` で区別している方式を踏襲）。

**一人あたり換算**：分母（人口等）は指標ごとに時点を明示。M3は `人口_人`（住基 令6.1.1）を分母に持つ。表示用人口（住基 令7.1.1）と決算の分母は時点が異なるため混同しない（§7.4の申し送り）。

## 4. 出力スキーマ（data-schema §3.2 を拡張）

各自治体JSONのレコード（または比較メタ）に、指標ごとに次を持たせる。§3.2の rank 系に類団・全国の平均を足す。

```
comparison: {
  value            : 当該自治体の値
  national_average : 全国平均（単純平均。母集団=その指標の全国データ保有市区町村）
  group_code       : 束ね後の類似団体区分コード
  group_average    : 類団平均（同一区分の単純平均）
  rank             : 順位（§3.2）
  rank_out_of      : 母数（§3.2）
  percentile       : 百分位（§3.2）
  average_method   : "unweighted_mean"（自作平均の既定）／"official" 等
  population_basis : 一人あたり系のみ。分母の時点（例 "住基R6.1.1"）
  source_note      : 母集団と時点の注記（UIの正直ラベル用）
}
```

- **V1の正直ラベル**（§3.2踏襲）：全国母集団を持つ指標のみ「全国平均/全国順位」を名乗る。岐阜42しか無い指標は「県内（収集済みN件中）」と明示し「全国」を詐称しない。類団平均も、全国母集団が揃った指標でのみ「類似団体平均」を表示する。
- **欠損**：比較値が出せない指標・自治体は `null`＋`source_note` に理由（無/確認できず/未収集を区別）。「確認できず」を0や空に丸めない。

## 6. 中立性（D-4/D-6/D-12/D-18 適用）

- 区分＝総務省の機械的分類、区分平均＝機械的な groupby 平均。ここに価値判断は入らない。
- 平均との差を**評価色・評価ラベル・順位付けの強調で見せない**。順位・百分位は事実として出すが、「良い/悪い」の色や語を付けない。
- 「上位N」抽出は生値の降順の機械的選択に限る（既存規律）。
- 加重方法の選択で意味が変わりうるため、既定は単純平均に固定し、公式加重値は別ラベルで併記（4節）。

## 7. スケール・外部依存

## 9. 実データ検証（2026-08-29・1-1a人口で実証）

本設計の集計段を、実ファイルで1指標通して検証した。使用：区分マスタ `ruikei_kubun_r06.xlsx`（市町村一覧・6桁団体コード・類団区分・1741団体）＋住基全国Excel `estat_000040306653`（統計表ID 000040306653・全国2273コード）。

- **結合キーは6桁団体コードの完全一致**。M3 `area_code`・区分マスタ・住基いずれも6桁で、そのまま結合できる（当初「先頭5桁照合」を試みたのは誤り。6桁完全一致が正）。M3岐阜42は区分マスタと **42/42一致・未一致0**。
- **母集団Mの定義（確定）**：`母集団M = 区分マスタに載る団体（1741）∩ 当該指標の全国ファイルに値がある団体`。住基は2273コード（都道府県・郡・政令市の区を含む）だが、区分マスタとの結合で**区・郡・都道府県は自動的に除外**され、市区町村単位1741に一致する。→ 明示的な「区を除く」フィルタは不要で、区分マスタ結合が母集団フィルタを兼ねる。
- **3種の比較値が算出できた**（例）：
  - 岐阜市＝束ね後区分「大都市」（全国128団体）・類団平均508,134人・全国平均71,413人・全国順位54/1741
  - 大垣市＝Ⅳ-2（75団体）・類団平均49,046人
  - 高山市＝Ⅱ-1（127団体）・類団平均28,010人
- **束ね写像も機能**：束ね後区分数20。政令指定都市・中核市・施行時特例市・特別区が「大都市」に集約され、一般市・町村類型（Ⅰ-1〜Ⅴ-2）はそのまま。
- **住基は男・女・計・世帯数を持つ**ため、人口だけでなく男女・世帯数も同一経路で比較値化できる（1-1aの複数フィールドを一括処理可）。

**結論**：§1（束ね写像）・§3（集計式）・§4（comparisonスキーマの各値）は実データで正しく計算できることを実証した。残る指標（1-1b/2a/3-2定数/3-3議会費total）も同一構造（全国集約ファイル × 区分マスタ6桁結合 × 束ね後groupby平均）で通せる。M2/M3は全国母集団が未収集のため、収集後に同経路で算出する（§7の外部依存）。**1-2bは2026-09-26に本経路で実装済み**（`scripts/m1_2b_daynight_comparison.py`）。全国母集団ファイル（estat_000032214141等）はローカルに既存していたため、収集段は不要だった。

## 10. コード桁数の2パターン（実装注意・2026-08-29）

結合キーは団体コードだが、**指標ソースによって桁数が異なる**。実装時に切り替えること（バグ源）。

| ソース系 | コード形式 | 例 | 区分マスタ（6桁）との結合 |
|---|---|---|---|
| 住基・決算統計・党派別人員調 等（総務省系） | **6桁**（全国地方公共団体コード） | `212016`＝岐阜市 | 6桁完全一致 |
| 国勢調査・SSDS 等（統計局系） | **5桁**（JIS X0402） | `21201`＝岐阜市。Excel内は `21201_岐阜市` 形式 | 区分マスタ6桁の**先頭5桁**で結合 |
| M1/M2/M3・区分マスタ | 6桁 | `212016` | そのまま |

- 実装は「指標ごとにコード形式（6桁/5桁）を宣言 → 5桁系は区分マスタ側を`code6[:5]`に落として結合」。1-2bで実証（岐阜42/42・母集団1740）。
- 5桁形式は Excel セル内で `21201_岐阜市` のように接頭辞になっていることがある。正規表現 `^(\d{5})_` で抽出する。
- 国勢調査の詳細表は男女×年齢の全展開（例1-2bは147385行）なので、**男女＝総数・年齢＝総数の行だけ**を市区町村単位として抽出する。既算出の比率列（1-2bのcol24＝昼夜間人口比率）があればそれを使い、無い指標は分子分母列から計算する。

**検証済み2指標**：1-1a人口（住基6桁・母集団1741）、1-2b昼夜人口比（国勢5桁・母集団1740）。両コード形式・実数系/比率系の両方で集計段が通ることを確認済み。
