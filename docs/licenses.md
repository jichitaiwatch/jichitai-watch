# 出典ライセンス台帳

作成日: 2026-08-06
位置づけ: `docs/20260805_decisions.md` 決定#7・C-4（Gemini・GPT指摘）の実装。CLAUDE.md「ライセンス」節の「data: public化前に要確認」という宿題を具体的な台帳に落とすもの。public化前に各データソースの利用条件を確認・記録し、規約違反のまま公開する事態を防ぐ。

**スコープ（今回）**：V1で実際に稼働しているM1〜M3の3ソースに限定。基礎データ層（社会増減・待機児童・医師数等）の各ソースは、実装（取得スクリプト作成）時にこの台帳へ1行ずつ追記する運用とする（`update_calendar.yaml`と同じ育て方）。

**追記（2026-10-03・`launch-backlog.md` D-11）**：V1の表示に使っている全ソースを棚卸しして追記した（「台帳（追記分）」節）。棚卸しの根拠は、カード定義の出典表記（`lib/card-registry.tsx`・`lib/pref-card-registry.tsx` の `sourceLabel`）と各 `data/*.json` の `sources` 欄の直接確認。各データの取得ファイルURL・取得日・ハッシュは `data/*.json` の `sources` 欄が正本で、本台帳には写さない（利用条件だけを持つ）。

---

## 総括

M1・M2・M3の主要3ソースは、いずれも**公共データ利用規約（第1.0版）＝PDL1.0**が適用される。加えて、本プロジェクトが各ソースから抽出するのは統計数値・表データが中心であり、PDL1.0本文・e-Stat規約とも「**数値データ、簡単な表・グラフ等は著作権による保護の対象ではなく、本利用ルールの適用なく自由に利用できる**」と明記している。したがってM1〜M3のデータ利用に関する法的リスクは低い。

ただし、以下2点は運用ルールとして必ず守る（PDL1.0が求める条件であり、かつ市民プラットフォームとしての信頼性の観点からも守るべき）：

1. **出典を記載する**（提供元・調査名・URL）。
2. **編集・加工して利用する場合は、加工した旨とその主体（自治体Watch）を記載する。** 加工した情報を、あたかも国・府省が作成した未加工のデータであるかのように見せることは禁止されている。

2点目は、本プロジェクトが公的データをAIで要約・再構成する性質上、特に重要。既存のVI原則（全カードに出典表示、AIサマリーは紫バッジで「非公式・非人間編集」を明示）は、この規約要件と方向性が一致している。
