# i18n/person-names — 首長・正副議長の氏名の読み（英語版・作業単位7）

決まり（2026-10-23 運営者裁定。`i18n/glossary.json` の `person_names`）：英語版の氏名は「姓・名」の順・普通の書き方（Yamada Haruo）で、漢字を添える（Yamada Haruo（山田 晴夫））。ローマ字は確かめた読みからヘボン式で機械的に作る（伸ばす音は畳み、記号は付けない。本人が使う綴りで上書きしない）。読みを確かめられなかった人は推測せず、英語版でも漢字のままにする（D-25）。

- `input-<回名>.csv`：調べる人の一覧（データから機械で作る。手で直さない）。列：id・団体コード・団体名・役職・氏名（データの表記）・参考URL。
- 外部AI（Grok・Composer）の結果は `_ai-out/names-<回名>-<grok|composer>.csv`（リポジトリに入れない）。Claude が突き合わせて裁定し、確定した読みを `readings-<回名>.csv` に残す（列：id・団体コード・団体名・役職・氏名・姓・名・姓の読み・名の読み・状態〈確定／確認できず〉・出典URL・確かめ方）。
- 読みは「その人」に付く。データの正副議長などが替わったら、新しい人の読みを調べて足す（読みの無い人は英語版でも漢字のまま）。

回：gifu（岐阜 127人）→ 愛知 → 三重・岡山 → 広島・山口。

補いの回：`input-followup1.csv`（4回で読みを確かめられなかった62人。列に「分かっている読み」〈姓か名の片方だけ分かっている人〉と「前回見た資料（読みが無かった）」を足した）。結果は元の回の `readings-<回名>.csv` の同じ id の行に反映する。2026-10-24 に62人全員の読みを確定（4回分の598人すべて確定。外部AIの結果は `poc/recon-20261024-names-followup1/`）。

英語版の氏名を作る：`python scripts/gen_person_names_en.py`（readings-*.csv の確定の行と `kanji-split.csv` から `i18n/person-names-en.json` を作る。手で直さない）。

- `kanji-split.csv`：姓・名のどちらかが2字以上で、読みに「伸ばす音に見える母音の並び（おう・おお・うう など）」か「キヤ・シユ などの並び」があるものの、漢字ごとの読みの区切り（例：井上＝い・の・うえ）。ローマ字は区切りごとに作ってつなぐ（伸ばす音は1つの区切りの中だけで畳む）。載っていないとスクリプトが止まる。人を足して止まったら、漢字ごとの読みを確かめて載せる。
- 読みの行を足したり直したりしたら、スクリプトを流し直して `i18n/person-names-en.json` もコミットする。
