# design/prefecture-outlines/

全47都道府県の輪郭SVGパス（先行生成資産）。**V1の`app/`コードからは一切参照していない。**

## これは何か

A-17（岐阜県アイコンの実輪郭化・`docs/launch-backlog.md`参照）で確立した「GeoJSON→RDP簡略化→SVGパス」手法を、運営者の依頼（2026-09-27「今のうちに全都道府県分作っちゃえばどう？」）により全県分へ一般化して先行生成したもの。`project-status.yaml`の`deferred`「他県展開」に備えた素材で、現時点でV1公開スコープには含まれない（D-17＝拡張未決の規律により、`app/`側のコードはA-17の岐阜県分以外を一切変更していない）。

## ファイル

- `prefecture-outlines.json` — 47都道府県分。キーは都道府県名（例：`"岐阜県"`）。各エントリ：
  - `viewBox` — 常に `"0 0 100 110"`（既存の岐阜県実装と同一規格）
  - `path` — SVG `<path d="...">` にそのまま渡せる文字列
  - `ringCount` — 採用したリング数（本土＋残した近接離島）
  - `vertexCount` — 55〜130の範囲に収まるようRDP簡略化済み
  - `droppedRemoteIslands` — 除外した遠隔離島リング数（例：東京都＝小笠原、沖縄県＝宮古・八重山、鹿児島県＝奄美群島）
  - `岐阜県`のみ追加で `note` — A-17本番パスへの固定である旨
- `contact-sheet.png` — 47県を並べたQA用一覧画像。目視確認済み（下記参照）。

## 生成方法

```
python3 scripts/generate_prefecture_outlines.py
```

標準ライブラリのみで完結（追加パッケージ不要）。`https://raw.githubusercontent.com/dataofjapan/land/master/japan.geojson` を都度フェッチして再生成する。手法の詳細（面積フィルタ・遠隔離島の距離フィルタ・RDP・投影・viewBox収め）はスクリプト冒頭のdocstringに記載。

**岐阜県のみ**、通常生成結果ではなくA-17で実機確認済みの本番パス（76頂点）に固定して上書きしている。他46県は本スクリプトの生成結果そのまま。

## 検証済みの内容（2026-09-27）

- 岐阜県の隣接7県（富山・石川・福井・滋賀・三重・愛知・長野）を合成し、方位・隣接関係が実際の地理と一致することを確認。
- 47県全件のコンタクトシートを目視、東京都・沖縄県・鹿児島県で遠隔離島が外接矩形を支配する問題を検出→距離フィルタ（1.8倍閾値）で解消。
- 愛媛県（佐田岬半島）・千葉県（房総半島）・京都府（丹後半島）等、代表的な細い地形がRDP簡略化後も判読可能な形で残っていることを個別確認。
- 沖縄県の細長い形状（本島＋近傍のみ）は簡略化の副作用ではなく地理的に正しい形であることを確認済み。

## 再現性についての注意

データソースはコミットSHA固定をしていない（`dataofjapan/land`は本プロジェクトと無関係の外部公開リポジトリのため、API経由のコミット参照は今回未実施）。再生成すると、上流データが更新されていた場合は結果が変わりうる。取得日の記録＝再現性の基準点として、生成日をスクリプトのdocstringおよび本READMEに残す（今回：2026-09-27）。

## 使うとき

他県展開に着手する際は、該当県のエントリを取り出し、岐阜県と同様に実機確認のうえ`app/`側へ反映すること（機械生成のパスをそのまま無検証で本番投入しない）。着手時は`docs/launch-backlog.md`の該当項目（本READMEの生成をJ節に記録済み）とD-17の規律を再確認する。
